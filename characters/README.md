# Персонажи

Постоянные вымышленные персонажи музыкального аккаунта. Создаются скиллом `/character-create` по [гайду](../docs/guides/music-reel.md).

```text
characters/<имя>/
  bible.md       описание и запреты, по шаблону templates/character-bible.md
  photos/        готовые фото персонажа, если создаёшь его не с нуля
  candidates/    варианты на выбор
  references/    утверждённый набор, основа всех рилсов
  tests/         проверочные сцены и пение
  input/         параметры запросов к моделям
  review.html    галерея, npm run review
```

**Готовые фото:** если персонаж уже создан нейросетью, положи снимки в `characters/<имя>/photos/` и запусти `/character-create`. Агент подготовит копии, поможет выбрать снимки для `references/` и проверит персонажа в деле. Нужны как минимум анфас и вполоборота. Для фото реального человека этот путь не настроен.

Тестовые персонажи создаются в папках `characters/test-<имя>/`. Они не попадают в git и в публичный клон движка.

В git хранится только `bible.md`. Изображения туда не попадают, поэтому `references/` обязательно копируй в резервное хранилище: это главный актив персонажа.
