# Siren

Локальный движок для генерации Instagram Reels музыкального аккаунта с постоянным вымышленным персонажем. Рендер строится на [Remotion](https://www.remotion.dev/), сценарии, разбор и правки идут через агента: [Claude Code, OpenCode или Codex](docs/guides/agents.md).

**Статус:** линия проверена на тестовом персонаже: форматы `talking-closeup` и `story-clip`. Все 13 скиллов рабочие, платный сценарий скиллами целиком ещё не проходил. OpenCode и Codex настроены, сценарий в них ещё не проходил. CLI нет, инструменты с пометкой ⚠️ ждут тестов.

**Первый раз:** [установка](docs/guides/transfer.md). После скачивания агент сам проведёт по всем шагам.

---

## Что делает

| Что | Как |
|---|---|
| Контент | Продвижение музыки через постоянного персонажа, пока на английском |
| Производство | Генерация через fal.ai и Remotion |
| Форматы | `talking-closeup`, `story-clip`. Только разобраны: `lyric-performance`, `cinematic-story` |

Музыка создаётся отдельно и приходит в движок готовым треком. Эта копия работает как обычная папка, без git.

---

## Как это работает

```text
Трек, текст песни, персонаж, референсы, тренды
  → бриф
  → фрагмент трека и тайминги
  → план съёмки и scenes.json
  → кадры и клипы через fal.ai
  → шаблон формата в Remotion
  → проверка и правки
  → MP4 и карточка с расходами
  → публикация вручную
```

## Структура

```text
accounts/    бренд аккаунта
ai/          контекст и исходники скиллов для ИИ-агентов
assets/      готовые треки, шрифты
characters/  персонажи
docs/        гайды и дорожная карта
engine/      код движка на Remotion
formats/     разбор и пакет каждого формата
published/   опубликованные рилсы
ref/         видео-референсы, только чтение
templates/   шаблоны брифов, карточек и скиллов
trends/      еженедельные разборы трендов
work/        текущие черновики
```

Правила для агентов: [AGENTS.md](AGENTS.md).

## Настройка

```bash
cp .env.example .env
```

- Нужен `FAL_KEY` с пополненным балансом fal.ai. Подойдёт любая модель fal, стоимость агент показывает перед каждым запуском.
- Список инструментов и статус проверки: [ai/context/stack.md](ai/context/stack.md).

## Резервные копии

Бинарные файлы в git не попадают: видео, аудио, изображения, шрифты и модели. Папки `ref/`, `assets/`, `characters/`, `published/` и `trends/` нужно копировать отдельно, иначе при потере диска их не восстановить. Важнее всего `characters/`: без референсов персонажа пропадёт его узнаваемость.
