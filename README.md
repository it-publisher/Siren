# Siren

Движок для создания Instagram Reels с AI-персонажем.

Для работы можно использовать чат с агентом: [Claude Code, OpenCode или Codex](docs/guides/agents.md) или CLI. Агент выбирает фрагмент трека, пишет план съёмки, генерирует кадры и клипы через [fal.ai](https://fal.ai), собирает ролик в [Remotion](https://www.remotion.dev/) и показывает его на проверку. Перед каждой платной генерацией он называет цену и ждёт подтверждения.

Форматы:

- `talking-closeup` — крупный план одним дублем без склеек. Персонаж поёт в студийный микрофон в тёмной комнате с тёплым светом, слова идут подписями капсом по 1–3 слова.
- `story-clip` — несколько планов встык под одну дорожку трека, без текста. Поющие планы чередуются с планами без пения, поверх лёгкая плёночная обработка.
- `lyric-performance` — персонаж поёт на тёмном фоне, крупные планы сменяются средними. Текст песни идёт строками рукописным шрифтом, в конце плашка стримингового сервиса.
- `cinematic-story` — история без текста из коротких планов по 2–3 секунды: общие и крупные планы героев, пейзажные перебивки. Самый дорогой формат, потому что планов много.

Для создания новых форматов — опишите их агенту или покажите референс.

## Установка

Mac (macOS 13.5 или новее, лучше 15) и агент. Git не нужен: движок скачивается архивом, а дальше агент сам ставит инструменты и ведёт до первого рилса. Вся инструкция в [гайде по установке](docs/guides/transfer.md).

Ручная установка:

```bash
cp .env.example .env    # впишите сюда FAL_KEY
cd engine
npm ci
npm run render:smoke    # должен появиться out/smoke.mp4
```

Ключ fal.ai хранится только в `.env`. `APIFY_TOKEN` нужен только для автосбора трендов, по умолчанию он выключен. Остальные команды описаны в [engine/README.md](engine/README.md).

## Структура

```text
accounts/    бренд аккаунта
ai/          контекст и скиллы для агентов
assets/      треки и шрифты
characters/  персонажи
docs/        гайды
engine/      код на Remotion
formats/     разборы и шаблоны форматов
published/   опубликованные рилсы
ref/         видео-референсы, их не трогаем
templates/   шаблоны брифов и карточек
trends/      разборы трендов по неделям
work/        черновики текущих рилсов
```
