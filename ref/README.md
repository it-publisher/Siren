# Референсы

Только чтение. Самих видео и картинок в репозитории нет: таблица показывает, по каким файлам сделаны разборы, а новые референсы кладутся сюда. Разбор хранится в [`formats/`](../formats/README.md).

| Реф     | Файл                    | Формат                                                        |
| ------- | ----------------------- | ------------------------------------------------------------- |
| Видео 5 | `lyric-performance.mp4` | [`lyric-performance`](../formats/lyric-performance/format.md) |
| Видео 6 | `talking-closeup.mp4`   | [`talking-closeup`](../formats/talking-closeup/format.md)     |
| Видео 7 | `cinematic-story.mp4`   | [`cinematic-story`](../formats/cinematic-story/format.md)     |

Новый референс называется по формату и разбирается скиллом `/format-add`.
