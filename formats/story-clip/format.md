# story-clip

**Реф:** нет, формат создан под задачу пользователя. **Аккаунт:** `music`. **Статус:** шаблон работает, сквозная проверка пройдена на двух роликах по 21 с с тестовым персонажем. Выбранная обработка: `look: film`. Рецепт реализма: [гайд по моделям](../../docs/guides/models.md).

## Механика

- Несколько планов идут встык под одну общую дорожку трека. Текста нет.
- Планы без пения делаются видеомоделью, на них трек звучит фоном или вокал идёт за кадром.
- Поющий план: кадр и чистый вокал в H3 Max, `sway: true` добавляет покачивание камеры. Связка Kling 4.0 и Sync-3 с облётом камеры на полном миксе пользователя не устроила, на чистом вокале не проверялась.
- Звук плавно входит за 0,3 с и уходит за 1,5 с, потому что фрагмент вырезан из середины трека.

## Запуск

```bash
cd engine
npx remotion render StoryClip ../work/<run-id>/render/final.mp4 --public-dir=../work/<run-id>
```

Клипы заранее делаются скриптом `npm run generate`, см. [гайд по моделям](../../docs/guides/models.md).

## Схема `scenes.json`

Проверяется при каждом рендере, ошибка останавливает сборку.

| Поле | Обязательно | Что это |
|---|---|---|
| `format` | Да | Всегда `story-clip` |
| `audioFile` | Да | Фрагмент трека на весь ролик |
| `look` | Нет | `film`: лёгкое приглушение цвета и зерно, вариант по умолчанию. `film-strong`: сильнее цвет, зерно и покачивание, приподнятый чёрный. Без поля обработки нет |
| `shots` | Да | Планы по порядку: `videoFile`, `seconds` и необязательный `sway: true` для покачивания камеры на неподвижном плане. Лишнее в конце клипа обрезается, звук клипа отключается |

Чтобы губы совпали, вокал вырезается из той же позиции трека, с которой план начинается в ролике: начало `audioFile` плюс сумма `seconds` предыдущих планов. Команды: `/clip-generate`.

## Что учесть

- **Промпт движения камеры:** покачивание и дуга на 45° в одном промпте у Kling 4.0 дали непрерывное движение без склейки. Поля `multi_prompt` намеренно не использовались.
- **Flash ставит свои склейки:** на 8-секундном клипе набережной модель сама сменила план на 4,8 с. Проверять поиском смены сцены через FFmpeg.
- **Разрешение:** клипы 720p растягиваются до 1080×1920. Варианты улучшения в [гайде по моделям](../../docs/guides/models.md).
- **Синхрон губ на слух** подтверждён только на клипе 7 с в 1080P. В 768P и на ролике целиком ещё нужно подтвердить.
- **Широкие планы** пока выглядят как ИИ: по умолчанию средние и крупные.
