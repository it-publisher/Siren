# talking-closeup

**Реф:** видео 6, `ref/talking-closeup.mp4`. **Аккаунт:** `music`. **Статус:** шаблон работает, сквозная проверка пройдена на 10 с с тестовым персонажем. Длинный ролик и публикация ещё не проверялись.

## Параметры рефа

960×720 (4:3), 30 fps, 34,3 с. Один план без склеек, камера слегка плавает.

## Механика

- Персонаж поёт или читает текст в студийный микрофон, тёмное помещение с тёплым светом.
- Русские подписи капсом по 1–3 слова, слева сверху.
- Звук похож на голос поверх ритма. Не транскрибирован, совпадение с губами не измерялось.

## Инструменты

Seedream 4.5 Edit, Demucs, MiniMax H3 Max Lip Sync, Whisper, Remotion. Можно взять и другие модели fal. Клип на 34 с в 768P стоит $3,26 без дублей.

## Запуск

```bash
cd engine
npm run transcribe -- --audio ../work/<run-id>/audio/vocal.wav --out ../work/<run-id>/timing/whisper.json --language en
npm run align -- --text ../work/<run-id>/script.md --timing ../work/<run-id>/timing/whisper.json --audio ../work/<run-id>/audio/vocal.wav --out ../work/<run-id>/timing/words.json
npx remotion render TalkingCloseup ../work/<run-id>/render/final.mp4 --public-dir=../work/<run-id>
```

Клип заранее делается скриптом `npm run generate`, см. [гайд по моделям](../../docs/guides/models.md).

## Схема `scenes.json`

Проверяется при каждом рендере, ошибка останавливает сборку.

| Поле | Обязательно | Что это |
|---|---|---|
| `format` | Да | Всегда `talking-closeup` |
| `videoFile` | Да | Клип от модели, путь от папки запуска. Звук клипа отключается, клип заполняет кадр 1080×1920 с обрезкой краёв |
| `audioFile` | Да | Фрагмент трека, совпадающий с клипом. Длина ролика берётся из `wordsFile` |
| `wordsFile` | Да | Обычно `timing/words.json`, результат `align` |

Подписи: капсом, по 1–3 слова, новая подпись начинается после знака препинания. На проигрыше подпись исчезает через 0,6 с.

## Что учесть

- Делаем сразу 9:16 и размещаем подписи заново.
- Подписи на языке аккаунта `music`, пока английском.
- Длинный единый план требует стабильной синхронизации губ: на 10 с кадр стабилен, синхрон на слух и длинный план не проверены.
- Whisper на вокале ошибается в словах и ставит метки `♪`. Текст подписей нужно брать из настоящего текста песни, от Whisper только тайминги.
