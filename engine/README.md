# Движок

**Статус:** основа. Работают проект Remotion, тайминги слов, проверочные композиции `Smoke` и `CaptionsCheck`, а также форматы [`talking-closeup`](../formats/talking-closeup/format.md) и [`story-clip`](../formats/story-clip/format.md). CLI ещё нет. Следующие шаги: [дорожная карта](../docs/roadmap.md).

## Установка

Нужен Node.js версий `^20.19.0`, `^22.13.0` или `>=24`. Remotion требует macOS 15 или новее.

На Apple Silicon инструменты ставятся через Homebrew: `brew install node ffmpeg uv`. На Intel Homebrew больше не собирает пакеты, поэтому нужны установщик Node.js, установщик uv и FFmpeg с evermeet.cx: команды в [`/music-start`](../ai/skills/music-start/SKILL.md).

| Инструмент | Для чего |
|---|---|
| FFmpeg | Фрагменты трека, проверка роликов, замеры |
| uv | Анализ битов, первый запуск скачивает librosa |
| Инструменты командной строки Xcode | Сборка Whisper, только для форматов с подписями. Homebrew ставит их сам, на Intel нужна команда `xcode-select --install` |

На Mac с памятью до 8 GB `remotion.config.ts` сам включает рендер в один поток и кэш видео 512 MB.

```bash
cd engine
npm ci
```

Папка `node_modules` занимает около 1 GB, из них 459 MB — браузер для рендера. В git она не попадает.

## Команды

Запускаются из `engine/`.

| Команда | Что делает |
|---|---|
| `npm run dev` | Открывает Remotion Studio |
| `npm run render:smoke` | Рендерит тест в `out/smoke.mp4` |
| `npm run lint` | Проверяет код: ESLint и TypeScript |
| `npm test` | Запускает тесты. Нужен Node.js от 23.6: тесты импортируют TypeScript напрямую |
| `npx remotion studio --public-dir=../work/<run-id>` | Открывает запуск в Studio |
| `npx remotion render TalkingCloseup ../work/<run-id>/render/final.mp4 --public-dir=../work/<run-id>` | Рендерит рилс `talking-closeup` |
| `npx remotion render StoryClip ../work/<run-id>/render/final.mp4 --public-dir=../work/<run-id>` | Рендерит рилс `story-clip` из нескольких планов |
| `npm run review -- --run <папка>` | Собирает галерею `review.html` запуска или персонажа: `frames/`, `clips/`, `render/`, `candidates/`, `references/`, `tests/` |
| `npm run generate -- --endpoint <модель> --input <json> --out <путь без расширения>` | ⚠️ Платно. Запрос к модели fal.ai: скачивает результат и пишет рядом `.json` с параметрами и `seed`. Нужен `FAL_KEY` в `.env`. Файлы передаются через `--reference <картинка>`, `--file <поле>=<путь>` или `--upload <поле>=<путь>`: последний кладёт файл в хранилище fal на сутки, для моделей без поддержки data URI. Если результат с этим `--out` уже сохранён, запрос не отправится: дублю нужен новый путь. Подходит любая модель fal |
| `npm run generate -- --resume --out <тот же путь>` | Забирает результат принятого запроса без новой оплаты: после обрыва, таймаута или ошибки загрузки. Запись запроса лежит в `<путь>.request.json`, пока она есть, новый запрос с этим `--out` не отправится. Чтобы отказаться от результата, удали файл |
| `npm run analyze-video -- --video <файл> --out <папка> [--frame-every <с>] [--scene-threshold <0–1>]` | Снимает размер, склейки, громкость и кадры в `metrics.json` и `frames/` |
| `npm run analyze-track -- --audio <файл> --out <json> [--fragment <с>] [--candidates <n>]` | Находит биты и самые энергичные фрагменты. Нужен `uv`, первый запуск скачивает librosa |
| `npm run transcribe -- --audio <файл> --out <json>` | Снимает тайминги через Whisper |
| `npm run align -- --text <txt> --timing <json> --audio <файл> --out <json>` | Переносит тайминги на текст сценария |

Для рендера нужна сеть: шрифты подгружаются через `@remotion/google-fonts`, чтобы их файлы не попадали в git.

## Тайминги

- **Whisper:** первый запуск собирает whisper.cpp и качает модель в `engine/.whisper/`, около 1,5 GB.
- **Готовая модель:** если `ggml-medium.bin` уже есть на диске, положи вместо загрузки символьную ссылку в `.whisper/models/`.
- ⚠️ **Обрыв загрузки:** библиотека проверяет только наличие файла и примет обрывок за готовую модель. После обрыва удали `.whisper/models/ggml-medium.bin`.

## Что проверено

| Проверка | Результат | Условия |
|---|---|---|
| Выходной файл | H.264, 1080×1920, 30 fps, 150 кадров, 5 с | M1 Pro, 32 GB, Node 26, macOS 15 |
| Кириллица | Inter и JetBrains Mono отображаются верно | Контрольный кадр |
| Remotion Studio | Открывается, таймлайн работает, правка `scenes.json` видна после перезагрузки, ошибка показана текстом | Тестовый запуск, встроенный браузер Claude Desktop, звук на слух не проверен |
| Whisper `medium` | 20 с аудио за 6,5 с | Русская речь, модель уже на диске |
| Начала слов | Отклонение от начала речи 38–67 мс | 6 границ предложений, FFmpeg `silencedetect` |
| `talking-closeup` | 10 с видео за 10 с, H.264, 1080×1920, 30 fps, 300 кадров, звук в файле. Подписи совпадают со словами на контрольных кадрах | Клип 768×1344 от H3 Max, синхрон на слух не проверен |
| `story-clip` | 21 с видео за 21 с, H.264, 1080×1920, 30 fps, 630 кадров, −13,9 LUFS, пик −1,9 dBFS | 3 клипа 720p, синхрон на слух не проверен |
| `analyze-track` | 123 BPM, 132 бита и 3 варианта фрагмента на треке 65 с, 42 бита на фрагменте 21 с | Точность битов на слух не оценена, припев не определяет |
| `analyze-video` | `lyric-performance`: 11 планов при 12 в ручном разборе | Плавные переходы не видит, число планов сверять по кадрам |
| `fal-generate --resume` | Результат забран без второго платного запроса, повторная отправка заблокирована | Только на поддельной очереди в тестах, настоящий обрыв не воспроизводился |
| Память рендера `story-clip`, 21 с | Сумма RSS завышена: по умолчанию 5,0 GB за 32 с, 2 потока 4,8 GB за 45 с, 1 поток 3,8 GB за 76 с | M1 Pro, 32 GB. На настоящих 8 GB не проверялось |
| Сборка под Intel | `npm ci`, `story-clip` за 302 с в один поток и `analyze-track` с `--no-build` прошли | x64-сборка Node.js через Rosetta на M1, это не скорость настоящего Intel |
| Дубль с тем же `--out` | Запрос не отправлен, файл и запись с `seed` не изменились, с новым путём дубль проходит | Только на поддельной очереди в тестах |

Время рендера зависит от формата и темы. Тест не показателен: сцена простая, а первый запуск дополнительно скачивает браузер.

## Известные предупреждения

`npm audit` показывает 10 предупреждений умеренной важности. Все они идут от одной уязвимости [`minimatch`](https://github.com/advisories/GHSA-g3hv-75wg-m249) в зависимостях ESLint. В рендер этот код не попадает, исправления пока нет.

## Планируемое устройство

- CLI: каждый шаг читает и пишет файлы в `work/<run-id>/`, поэтому шаги можно связать в полную автоматизацию.
