## Скиллы

Исходники лежат в `ai/skills/<имя>/SKILL.md`. Агенты находят их через символические ссылки: Claude Code в `.claude/skills/<имя>`, Codex и OpenCode в `.agents/skills/<имя>`. Подробнее: [агенты](../docs/guides/agents.md).

**Все скиллы рабочие,** ограничения указаны в начале каждого. Платный сценарий `music` пройден скиллами целиком. У платных `character-create`, `shot-frames`, `clip-generate`, а также у `publish-package` автозапуск выключен: в Claude Code `disable-model-invocation: true`, в Codex `agents/openai.yaml`, в OpenCode правило `ask` в `opencode.json`. Агент не запустит их сам, только пользователь.

## Как довести новый скилл до рабочего

1. Реализовать нужную часть в `engine/` и проверить на реальном запуске.
2. Заполнить в `SKILL.md` точные команды, форматы файлов и проверки.
3. Убрать строку статуса «шаблон» и закрытые пункты из «Открытых вопросов».
4. Выключать автозапуск у скиллов с платной генерацией и публикацией. Безопасному скиллу убрать `disable-model-invocation` и добавить его в `allow` в `opencode.json`.
5. Обновить таблицу выше и `context/stack.md`.

## Новый скилл

Скопируй [../templates/skill.md](../templates/skill.md) в `ai/skills/<имя>/SKILL.md` и создай ссылки из корня репозитория. Имя: строчные латинские буквы, цифры и дефисы, совпадает с папкой, иначе OpenCode его не примет.

```bash
ln -s ../../ai/skills/<имя> .claude/skills/<имя>
ln -s ../../ai/skills/<имя> .agents/skills/<имя>
```

Если автозапуск нужно выключить, добавь `ai/skills/<имя>/agents/openai.yaml` с `policy.allow_implicit_invocation: false`, как у `clip-generate`.
