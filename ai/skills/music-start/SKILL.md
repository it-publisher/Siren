# music-start

> **Статус:** инструкция написана, на чистом Mac ещё не проходила. Платные шаги внутри неё скиллами целиком тоже не проходили: о найденных ошибках сразу говори пользователю.

## Назначение

Вести человека без опыта разработки по всем шагам: задавать вопросы, делать техническую часть и останавливаться там, где решает он. Гайд, на который опирается скилл: [музыкальный рилс](../../../docs/guides/music-reel.md).

## Как вести разговор

- Пиши по-русски, на «ты», простыми словами. Термин объясняй при первом упоминании.
- За раз задавай один вопрос. Дождись ответа, потом переходи дальше.
- В конце каждого сообщения называй следующий шаг: что сделаешь ты и что нужно от человека.
- Команды выполняй сам. Просить человека о Терминале можно только там, где это указано в шагах.
- Git не используй и не предлагай.
- Подтверждение цены и оценку на слух за человека не делай. Клипы описывай только по тому, что видно на кадрах, удачными не называй.

## Защита ключа и денег

- ⛔ Никогда не читай и не показывай значение ключа: не выводи `.env` на экран и не открывай его своими инструментами. Проверять можно только командой из шага 3.
- ⛔ Если человек вставил ключ в чат, сразу скажи удалить этот ключ на странице ключей fal.ai и создать новый. Старый нигде не записывай.
- ⛔ Перед каждым платным запросом покажи цену и дождись ответа.
- ⛔ Если платный шаг упал с ошибкой, не отправляй запрос заново. Сначала проверь `<out>.request.json` и забери результат: `npm run generate -- --resume --out <путь>`.

## Где человек сейчас

Запускай из корня проекта в начале каждого нового разговора. Ничего не спрашивай про то, что видно по файлам.

```bash
sw_vers -productVersion; uname -m; sysctl -n hw.model; echo "$(( $(sysctl -n hw.memsize) / 1024 / 1024 / 1024 )) GB"
for tool in node ffmpeg uv; do printf '%s: ' "$tool"; command -v "$tool" || echo missing; done
node -v 2>/dev/null
test -f .env && grep -Eq '^FAL_KEY=[^[:space:]"'"'"']+$' .env && echo key-ok || echo key-missing
test -d engine/node_modules && echo deps-ok || echo deps-missing
test -f engine/out/smoke.mp4 && echo smoke-ok || echo smoke-missing
find characters -path 'characters/test-*' -prune -o -type f -path '*/references/*' -print | head -1
find work -mindepth 1 -maxdepth 1 -type d -name '*-music-*'
```

Начни с первого невыполненного шага. Если всё готово и запуск уже есть, продолжи его, см. шаг 6.

## Шаги

### 1. Знакомство

Если это первый разговор, коротко скажи, что будет дальше: установка, персонаж, первый рилс. Предупреди: платный путь скиллами целиком ещё не проходили, поэтому возможны ошибки, а переделки стоят денег. Затем спроси по одному:

1. Есть ли аккаунт fal.ai с пополненным балансом. На старт ориентир около $10: персонаж $2,40, первый рилс $3 и запас на переделки.
2. Есть ли готовый трек и его текст. Без них можно установить движок, но не закончить проверку персонажа и рилс.

Проверь версию macOS:

| macOS | Что делать |
|---|---|
| 15 и новее | Продолжай |
| 13.5–14 | Предупреди: Remotion официально требует macOS 15 и может не собрать видео. Если macOS 15 на этом Mac ставится, предложи обновиться. Иначе продолжай: тестовый рендер покажет результат, запасной путь описан в разделе «Если рендер не идёт» |
| Ниже 13.5 | ⛔ Нужный Node.js не запустится. Останови установку и скажи об этом прямо, предложи обновить macOS или взять другой Mac |

Если на Mac 8 GB памяти или меньше, предупреди: рендер пойдёт в один поток и будет медленнее, на это время лучше закрыть браузер и лишние программы. Настройка включается сама в `engine/remotion.config.ts`.

### 2. Инструменты

Нужны Node.js версий `^20.19.0`, `^22.13.0` или `>=24`, FFmpeg и uv. Назови, каких не хватает, и дождись согласия на установку. Способ зависит от процессора, его показывает `uname -m`.

Некоторые команды ниже скачивают и запускают программы, поэтому агент может спросить разрешение или получить отказ. ⛔ Отказ не обходи: объясни, что делает команда, и дай её человеку для Терминала. Terminal находится через Cmd+Пробел.

**`arm64`, Apple Silicon:**

```bash
brew install node ffmpeg uv
```

Если `brew` не найден, проверь `/opt/homebrew/bin/brew`. Если его нет совсем, попроси запустить в Терминале команду ниже. Объясни: программа попросит пароль от Mac, при вводе символы не видны, а пароль в чат присылать нельзя. Если после установки `brew` не находится, выполни блок `Next steps` из вывода установщика.

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

**`x86_64`, Intel:** ⛔ Homebrew не используй. Он больше не собирает пакеты для Intel, поэтому начнёт компилировать их из исходников. Ставь только недостающее:

1. Node.js, установщик подписан и проверен Apple. Человек проходит окна установщика и вводит пароль от Mac в окне системы:

   ```bash
   curl -fsSL -o ~/Downloads/node-v26.13.0.pkg https://nodejs.org/dist/v26.13.0/node-v26.13.0.pkg
   open ~/Downloads/node-v26.13.0.pkg
   ```

2. uv:

   ```bash
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```

3. FFmpeg и ffprobe со страницы [evermeet.cx](https://evermeet.cx/ffmpeg/), файлы без подписи:

   ```bash
   mkdir -p ~/.local/bin
   for tool in ffmpeg ffprobe; do
     url=$(curl -fsSL "https://evermeet.cx/ffmpeg/info/$tool/release" | node -p 'JSON.parse(require("fs").readFileSync(0)).download.zip.url')
     curl -fsSL -o "/tmp/$tool.zip" "$url" && unzip -oq "/tmp/$tool.zip" -d ~/.local/bin
   done
   ```

4. Проверь, что всё находится в новой оболочке. Если `~/.local/bin` нет в `PATH`, добавь его в `~/.zshrc`:

   ```bash
   zsh -ic 'command -v node ffmpeg ffprobe uv; node -v; ffmpeg -hide_banner -filters | grep -c ebur128'
   ```

### 3. Ключ fal.ai

1. Попроси создать ключ на [странице ключей](https://fal.ai/dashboard/keys). Баланс пополняется в [разделе оплаты](https://fal.ai/dashboard/billing). Напомни: ключ не присылать в чат.
2. Создай файл и открой его в TextEdit:

   ```bash
   test -f .env || cp .env.example .env
   chmod 600 .env
   open -e .env
   ```

3. Попроси вставить ключ сразу после `FAL_KEY=` без пробелов и кавычек, сохранить через Cmd+S и закрыть окно.
4. Проверь без вывода значения:

   ```bash
   grep -Eq '^FAL_KEY=[^[:space:]"'"'"']+$' .env && echo key-ok || echo key-missing
   ```

Рабочий ли ключ, станет ясно на первой генерации. Баланс человек смотрит в разделе оплаты.

### 4. Подготовка движка

Предупреди, что скачается около 1 GB. Команды запускаются из `engine/`:

```bash
npm ci
npm run render:smoke
ffprobe -v error -select_streams v:0 -show_entries stream=codec_name,width,height,r_frame_rate -of csv=p=0 out/smoke.mp4
open out/smoke.mp4
```

Ожидается `h264,1080,1920,30/1`. ⛔ Попроси подтвердить, что видео открылось. Если шаг упал, покажи причину простыми словами. Первый рендер может упасть с ошибкой `Timed out after 25000 ms while trying to connect to the browser`: браузер запускается в первый раз дольше лимита, деньги не тратятся. Повтори команду до двух раз. Если не помогло или ошибка другая, переходи к разделу «Если рендер не идёт».

### 5. Персонаж

1. Открой папку для трека командой `open assets/tracks` и попроси перетащить туда файл. Текст песни попроси прислать в чат и сохрани рядом с треком как `<название>.txt`.
2. Спроси, есть ли готовые фото персонажа или создаём его с нуля. Скажи, сколько стоит каждый путь: с готовыми фото около $1,72 за проверку, с нуля около $2,36.
3. Если создаём с нуля, спроси по одному: имя персонажа латиницей, возраст (только взрослый), внешность, стиль и жанр. Если человек не знает, предложи 2–3 варианта. Персонаж вымышленный и намеренно не похож на реальных людей. Покажи собранное описание. Если фото есть, спроси только имя латиницей: остальное скилл уточнит сам в разделе «Если есть готовые фото».
4. Этот скилл платный и сам не запускается. Попроси человека написать `/character-create`, в OpenCode `@character-create`, в Codex `$character-create`, и добавить «с нуля» или «есть готовые фото». Уже собранное повторно не спрашивай.
5. Когда набор зафиксирован, переходи к шагу 6.

### 6. Первый рилс

Для первого раза предложи `story-clip`: около $2,90 за 21 с, без подписей и установки Whisper. `talking-closeup` стоит около $3,30 за 34 с и при первом снятии таймингов скачивает примерно 1,5 GB. На Mac с 8 GB Whisper не замерялся, поэтому начинай со `story-clip`.

Веди по таблице. Определи текущий шаг по файлам в `work/<run-id>/`. Платные скиллы и `/publish-package` человек запускает сам, в таблице они отмечены. В других агентах запись скилла меняется так же, как в шаге 5.

| Шаг | Скилл | Файл готового шага | Что решает человек |
|---|---|---|---|
| Создать запуск | `/reel-new` | `brief.yaml` | Формат, настроение, призыв к действию |
| Выбрать фрагмент | `/track-prepare` | `audio/fragment.wav` | Выбирает на слух |
| Снять тайминги, только `talking-closeup` | `/transcribe-timing` | `timing/words.json` | Сверяет текст песни |
| План съёмки | `/scene-plan` | `scenes.json` | Правит и утверждает |
| Кадры, платно, запускает человек | `/shot-frames` | `frames/` | **Главное решение перед основными тратами** |
| Клипы, платно, запускает человек | `/clip-generate` | `clips/` | Подтверждает цену, решает, что переделать |
| Сборка | `/remotion-compose` | Правки в Studio | Просит правки |
| Рендер и проверка | `/render-check` | `render/final.mp4` | Смотрит финал |
| Пакет, запускает человек | `/publish-package` | `published/music/<run-id>/` | Подтверждает описание |

Картинки и клипы показывай в галерее: `npm run review -- --run ../work/<run-id>`, затем `open ../work/<run-id>/review.html`.

### Если рендер не идёт

Если тестовый рендер падает и после исправлений, не останавливай работу. Всё, кроме сборки, идёт без Remotion: кадры и клипы считаются на серверах fal.ai.

1. Пройди шаги 5 и 6 до `/clip-generate`. Предпросмотр в Studio при этом недоступен.
2. Упакуй запуск: `ditto -c -k --keepParent work/<run-id> ~/Desktop/<run-id>.zip`. Ключей в этой папке нет.
3. Попроси передать архив человеку с рабочим движком. Он распаковывает его в свою папку `work/` и рендерит команду формата из `engine/README.md`.
4. Готовый файл положи в `work/<run-id>/render/final.mp4` и продолжи с `/publish-package`.

### 7. После рендера

1. Напомни опубликовать ролик вручную с телефона и поставить метку ИИ.
2. Попроси через 1 и 7 дней прислать результаты, запиши их в карточку запуска.
3. Покажи итог расходов из карточки и спроси, что менять в следующем рилсе. Следующий рилс начинается с `/reel-new`, персонажа заново не создаём.

## Выход

Рабочий движок на устройстве, персонаж в `characters/<имя>/`, первый ролик в `published/music/<run-id>/`.

## Проверки

- Значение ключа ни разу не появилось в чате и выводе команд.
- Ни один платный запрос не ушёл без подтверждённой цены.
- Человек сам подтвердил фрагмент, кадры, губы и финал.

## Открытые вопросы

- На чистом Mac установка не проверялась: команды скачивания, определения этапа, `npm ci` и рендера пройдены на Mac, где инструменты уже стояли. Установка Homebrew и инструментов не запускалась.
- Intel проверен x64-сборками через Rosetta на M1, а не на настоящем Intel: скорость и работа на 8 GB не подтверждены. Установка Node.js и uv этим способом и запуск FFmpeg от evermeet не проверялись, FFmpeg проверен только чтением файла.
- Remotion 4.0.430 рассчитан на macOS 13 и мог бы подойти для macOS 13.5–14, но с этим движком не проверялся.
- Открытие `.env` в TextEdit не проверялось. Команда проверки формата ключа пройдена на тестовых значениях.
