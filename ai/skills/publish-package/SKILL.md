# publish-package

> **Статус:** работает. Команды проверены на другом формате, на музыкальном рилсе ещё не запускались. Сама публикация остаётся ручной. Автозапуск выключен, так как шаг ведёт к публикации.

## Назначение

Перенести результат в `published/` и подготовить всё для публикации.

## Вход

`work/<run-id>/` с `render/final.mp4` и `checks/report.md`.

## Шаги

1. Проверить, что отчёт есть и без открытых дефектов, а в карточке нет нерешённых отметок. Если команда что-то нашла, остановись и покажи это пользователю.

   ```bash
   grep -n "⚠️" work/<run-id>/card.md
   ```

2. Заполнить в `card.md` расходы.
3. Написать описание рилса в `work/<run-id>/caption.txt`.
4. Показать пользователю описание и карточку. ⛔ Без его подтверждения дальше не идём.
5. Скопировать файлы из корня репозитория. Файла `script.md` может не быть: он есть только у форматов с подписями.

   ```bash
   RUN=<run-id>; D="published/music/$RUN"; mkdir -p "$D"
   cp "work/$RUN/render/final.mp4" "work/$RUN/brief.yaml" "work/$RUN/scenes.json" "work/$RUN/card.md" "work/$RUN/caption.txt" "$D/"
   for F in script.md shot-plan.md; do if [ -f "work/$RUN/$F" ]; then cp "work/$RUN/$F" "$D/"; fi; done
   ```

6. Напомнить пользователю поставить метку ИИ.
7. После публикации записать дату и ссылку в `card.md` в обеих папках. Через 1 и 7 дней туда же идут результаты.

## Выход

`published/music/<run-id>/`.

## Проверки

- Отчёт проверки без открытых дефектов.
- Пользователь подтвердил готовность.

## Открытые вопросы

- Требования к метке ИИ известны по пересказам правил Meta: сверить со справкой Instagram.
- Автопубликация через Instagram API откладывается на поздний этап.
