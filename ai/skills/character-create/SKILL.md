# character-create

> **Статус:** работает, требуется `FAL_KEY`. Команды и промпты взяты из ручного создания тестового персонажа, скиллом целиком платный прогон ещё не проходил. Автозапуск выключен: шаг платный. Ветка с готовыми фото ещё не проходила платный прогон: её подготовка снимков проверена на тестовых файлах.

## Назначение

Создать персонажа, который переиспользуется во всех рилсах.

## Вход

Пожелания пользователя к образу и жанр музыки или готовые фото персонажа. Для проверки пения: трек или его фрагмент от 10 с.

## Модели

По умолчанию из [гайда по моделям](../../../docs/guides/models.md): Seedream 4.5, Seedream 4.5 Edit, MiniMax H3 Max Lip Sync в 768P, Demucs, Kling 4.0. Пользователь может назвать любую модель fal: сверь её схему на `fal.ai/models/<адрес>/api` и цену на странице модели.

## Шаги

Если есть готовые фото персонажа, начни с раздела «Если есть готовые фото». Команды запускаются из `engine/`.

1. Заполнить `characters/<имя>/bible.md` по `templates/character-bible.md`. Базовый промпт на английском, с цветом глаз и фразой `fictional adult`. Имена артистов и реальных людей в промпт не писать.
2. Показать оценку и дождаться подтверждения. ⛔ Без него платные запросы не отправлять.

   | Этап | Объём | Цена |
   |---|---|---|
   | Кандидаты, Seedream 4.5 | 10 кадров | $0,40 |
   | Набор референсов, Seedream 4.5 Edit | 6 кадров | $0,24 |
   | Сцены, Seedream 4.5 Edit | 3 кадра | $0,12 |
   | Вокал, Demucs | 10 с | $0,01 |
   | Пение, H3 Max, 768P | 10 с | $0,80 |
   | План без пения, Kling 4.0, 720p | 5 с | $0,79 |
   | **Итого без переделок** | | **$2,36** |

3. Сгенерировать кандидатов. На каждый вариант свой `input/candidate-NN.json`:

   ```json
   { "prompt": "<описание со съёмкой со стороны>", "image_size": "portrait_16_9", "num_images": 1, "max_images": 1 }
   ```

   ```bash
   npm run generate -- --endpoint fal-ai/bytedance/seedream/v4.5/text-to-image --input ../characters/<имя>/input/candidate-01.json --out ../characters/<имя>/candidates/candidate-01
   npm run review -- --run ../characters/<имя>
   ```

4. ⛔ Пользователь выбирает лицо в галерее `characters/<имя>/review.html`.
5. Собрать набор в `references/`: `front-neutral`, `three-quarter`, `profile`, `full-body`, `smile`, `microphone`. Первым делается `front-neutral` по выбранному кандидату: анфас, рот закрыт, простой фон. Остальные делаются по нему.

   ```bash
   npm run generate -- --endpoint fal-ai/bytedance/seedream/v4.5/edit --input ../characters/<имя>/input/three-quarter.json --out ../characters/<имя>/references/three-quarter --reference ../characters/<имя>/references/front-neutral.jpg
   ```

   В каждом промпте: `The same woman as in Figure 1`, цвет глаз, съёмка со стороны с двух метров, простая стена, ровный дневной свет. Микрофон: сложные детали оставлять размытыми.

6. ⛔ Пользователь подтверждает, что на всех кадрах один человек. Переделывать только отклонённые.
7. Проверить в деле, файлы в `tests/`:
   - три сцены в Seedream 4.5 Edit с разным светом и местом;
   - 10 секунд пения: команды `clip-generate`, шаги с Demucs и H3 Max;
   - один план без пения: команда `clip-generate`, Kling 4.0.
8. ⛔ Пользователь решает, узнаётся ли персонаж, и на слух оценивает губы. Агент описывает только то, что видно на кадрах, и не называет клип удачным.
9. Заполнить в `bible.md` таблицу референсов и журнал с расходами.
10. Дальше персонажа не генерировать заново. Новая одежда или причёска означают дополнение набора по шагу 5.

Если лицо плывёт даже с набором, предложи [FLUX.2 Trainer](https://fal.ai/models/fal-ai/flux-2-trainer): нужно от 20 наборов данных, цену сверить на странице.

## Если есть готовые фото

Заменяет шаги 1–6, дальше идут шаги 7–10. Лицо не генерируется, поэтому проверка стоит около $1,72 вместо $2,36: сцены $0,12, вокал $0,01, пение $0,80, план без пения $0,79. Команды запускаются из корня проекта.

1. Спроси, кто на фото. Отвечает пользователь: по снимку этого надёжно не определить.

   | На фото | Что делать |
   |---|---|
   | Вымышленный взрослый персонаж, созданный нейросетью | Продолжай |
   | Реальный человек, в том числе сам пользователь | ⛔ Эта ветка для него не настроена: правила, шаблон `bible.md` и промпты рассчитаны на вымышленного персонажа. Останови её и предложи создать вымышленного персонажа с нуля |
   | Персонаж выглядит несовершеннолетним или намеренно похож на реального человека | ⛔ Не используй и объясни почему |

2. Создай папку и попроси перетащить туда фото. Подходят JPG, PNG и HEIC с iPhone. Оригиналы здесь не меняются.

   ```bash
   mkdir -p characters/<имя>/photos && open characters/<имя>/photos
   ```

3. Подготовь копии. Команда учитывает поворот снимка, уменьшает длинную сторону до 4096 пикселей и удаляет метаданные: в снимках с телефона бывает записано место съёмки, а референсы уходят на серверы fal.ai. О файлах со строкой `failed` скажи пользователю и попроси прислать их в JPG.

   ```bash
   C=characters/<имя>; TMP=$(mktemp -d); mkdir -p "$C/candidates" "$C/references"
   for F in "$C"/photos/*; do
     N=$(basename "${F%.*}")
     if sips -s format jpeg "$F" --out "$TMP/$N.jpg" >/dev/null 2>&1 && ffmpeg -hide_banner -v error -y -i "$TMP/$N.jpg" -vf "scale='min(4096,iw)':'min(4096,ih)':force_original_aspect_ratio=decrease" -map_metadata -1 -q:v 2 "$C/candidates/$N.jpg"; then echo "ok: $N"; else echo "failed: $F"; fi
   done
   rm -rf "$TMP"
   ```

4. Собери галерею и открой её. Затем посмотри каждый кадр и опиши, что видно: один ли человек в кадре, видно ли лицо, не закрыто ли оно, похож ли человек на других снимках.

   ```bash
   (cd engine && npm run review -- --run ../characters/<имя>)
   open characters/<имя>/review.html
   ```

5. ⛔ Вместе с пользователем выбери снимки и скопируй их под именами из шага 5 основного порядка. Обязательные файлы: `front-neutral.jpg` (анфас, рот закрыт) и `three-quarter.jpg` (вполоборота), на них ссылаются команды кадров и клипов. Остальные можно добавить позже.

   ```bash
   cp "characters/<имя>/candidates/<снимок>.jpg" characters/<имя>/references/front-neutral.jpg
   ```

   Если ракурса не хватает, попроси другое фото или предложи догенерировать его по шагу 5 основного порядка, по $0,04 за кадр и только после подтверждения цены.

6. Заполни `characters/<имя>/bible.md`: внешность опиши по снимкам, а возраст, цвет глаз, стиль и жанр уточни у пользователя. Базовый промпт на английском, с цветом глаз и фразой `fictional adult`.
7. ⛔ Покажи описание, набор и цену проверки, дождись подтверждения. Затем переходи к шагу 7 основного порядка.

## Выход

`characters/<имя>/`: `bible.md`, `candidates/`, `references/`, `tests/`, `input/`, `review.html`. С готовыми фото ещё `photos/`.

## Проверки

- Персонаж вымышленный, взрослый, без намеренного сходства с реальными людьми.
- На всех референсах один и тот же человек, цвет глаз совпадает.
- Пользователь подтвердил узнаваемость и губы на тестах.
- Все расходы записаны в журнал `bible.md`.

## Открытые вопросы

- Держится ли лицо на длинной серии рилсов: на тестовом персонаже проверено только в тестовых роликах.
