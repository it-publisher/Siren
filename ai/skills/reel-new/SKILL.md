# reel-new

> **Статус:** работает, музыкальные запуски создаются этим скиллом.

## Назначение

Начать работу над рилсом: создать папку запуска и бриф.

## Вход

Формат, персонаж, трек, текст песни, настроение и референсы.

## Шаги

1. Определить `run-id` вида `YYYY-MM-DD-music-<slug>`.
2. Проверить, что формат работает: по таблице в `formats/README.md` сейчас это `talking-closeup` и `story-clip`. Остальные форматы только разобраны, о них надо сказать пользователю.
3. Создать папку и файлы из корня репозитория. Существующий запуск не перезаписывать:

   ```bash
   RUN=<run-id>
   test ! -e "work/$RUN" && mkdir -p "work/$RUN/audio" "work/$RUN/timing" "work/$RUN/render" "work/$RUN/checks" && cp templates/brief.music.yaml "work/$RUN/brief.yaml" && sed "s/<run-id>/$RUN/" templates/card.md > "work/$RUN/card.md"
   ```

4. Заполнить `brief.yaml`: персонаж, трек, текст песни, длина фрагмента, настроение, призыв к действию. Если персонажа нет, сначала `/character-create`.
5. Заполнить в `card.md` аккаунт `music` и формат.
6. Показать бриф пользователю. ⛔ Формат и призыв к действию подтверждает он.
7. Назвать следующий шаг по [гайду](../../../docs/guides/music-reel.md).

## Выход

`work/<run-id>/brief.yaml`, `work/<run-id>/card.md`.

## Проверки

- Команда шага 3 не сработала вхолостую: при существующей папке она ничего не создаёт, тогда спроси, продолжать ли старый запуск.
- Пользователь подтвердил бриф.

## Открытые вопросы

- Выбор формата автоматически или только вручную. Пока вручную.
