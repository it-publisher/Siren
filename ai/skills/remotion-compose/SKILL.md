# remotion-compose

> **Статус:** работает для всех форматов с шаблоном. Открытие, переход по таймлайну, правка `scenes.json` и показ ошибок проверены на другом формате. Звук в Studio на слух не проверялся.

## Назначение

Показать ролик в Remotion Studio для правок.

## Вход

`scenes.json`, `audio/`, `timing/`.

## Шаги

1. Запустить Studio с папкой запуска. Сервер не должен блокировать работу агента, поэтому запускай его в фоне и дай пользователю ссылку.

   ```bash
   cd engine && npx remotion studio --public-dir=../work/<run-id> --no-open --port=3000
   ```

   В Claude Desktop вместо этого можно показать Studio во встроенном браузере: создай `.claude/launch.json` с абсолютными путями и открой конфигурацию `studio` через `preview_start`. Файл в git не попадает: у каждого свои пути и запуск.

   ```json
   {
     "version": "0.0.1",
     "configurations": [
       {
         "name": "studio",
         "runtimeExecutable": "npm",
         "runtimeArgs": ["--prefix", "<корень>/engine", "run", "dev", "--", "--public-dir=<корень>/work/<run-id>", "--no-open", "--port=3000"],
         "port": 3000
       }
     ]
   }
   ```

2. Открыть композицию формата: `http://localhost:3000/<Имя>`, где имя `TalkingCloseup` или `StoryClip`.
3. Вносить правки в `scenes.json`, а не в шаблон. Шаблон меняется, только если проблема общая для формата.
4. После каждой правки перезагрузить страницу: **сама Studio файл не перечитывает**. Если файл неверный, вместо ролика появится текст ошибки с номером сцены.
5. ⛔ Пользователь смотрит ролик и решает, что менять. Когда закончите, останови сервер.

## Выход

Обновлённый `scenes.json`.

## Проверки

- Важное содержимое в безопасной зоне.
- Подписи совпадают со звуком.
- Экран меняется в ритм музыки.

## Открытые вопросы

- Размер безопасной зоны: сторонние гайды расходятся, проверим тестовой публикацией.
