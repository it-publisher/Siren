# Обязательные правила

## Люди и голоса

- Только вымышленные взрослые персонажи.
- Не генерировать внешность и голоса реальных людей без их явного согласия.
- Не использовать имена артистов и реальных людей в промптах для подражания.

## Метка ИИ

- Перед публикацией напоминать о метке ИИ для реалистичного видео и реалистичного голоса.
- Требования известны по пересказам правил Meta, поэтому перед первым запуском сверить их со справкой Instagram.

## Деньги

- Бюджет решает пользователь, потолков и лимитов в движке нет.
- Перед каждым платным запуском показывать оценку стоимости и ждать подтверждения.
- Цену сверять на странице модели с учётом разрешения и длительности. API цен может отдавать только минимальную: у Kling 4.0 это цена за 720p, а 1080p в полтора раза дороже.
- Сначала утверждаются дешёвые этапы (текст и кадры), затем дорогие (видео).
- Фактический расход записывается в карточку запуска.
- Защиту платных запросов агент не обходит без прямого указания пользователя. Скрипт запускается только командой `npm run generate`, без другой формы записи и прямого вызова: на неё настроено правило `ask` в `opencode.json`. Блокировки по `--out` не снимаются удалением `<out>.json`.

## Модели

- Модели в гайдах — значения по умолчанию. Пользователь может взять любую модель fal, отсутствие модели в гайде не блокирует работу.
- Для новой модели сверить схему и цену на её странице и записать результат в [гайд по моделям](../../docs/guides/models.md).

## Тренды

- По умолчанию данные собираются вручную из Reels Trends.
- Автосбор через сторонние скрейперы включается только по явному решению пользователя и после проверки условий Meta.
