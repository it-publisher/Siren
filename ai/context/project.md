# Контекст проекта

## Цель

Создавать Reels для продвижения музыкального Instagram-аккаунта. Сначала черновик с ручными правками, затем полная автоматизация.

## Аккаунт

| Параметр | Значение |
|---|---|
| Тема | Продвижение музыки |
| Лицо аккаунта | Постоянный вымышленный персонаж |
| Инструменты | Любые модели fal.ai и Remotion |
| Звук | Готовые треки, созданные отдельно |
| Тренды | Идеи и приёмы |
| Бренд | Строится вокруг персонажа |
| Язык | Пока английский |

## Вход и выход

- **Вход:** трек и его текст, персонаж, референсы.
- **Выход:** MP4 1080×1920, 30 fps, и карточка с исходниками и расходами.

## Ограничения

- Remotion подпадает под Free License: она действует для команд до 3 человек.
- Условия Anthropic запрещают делить аккаунт Claude.
- В приоритете бесплатные инструменты, платные допустимы.
- Бюджет решает пользователь. Агент показывает стоимость генерации и ждёт одобрения.
- Локальная генерация видео в план не входит: на M1 Pro с 32 GB её качества мало.
- Рефы-видео добавляются файлами, автоскачивание из Instagram не закладываем.
