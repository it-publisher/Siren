# Гайд: модели

Какие модели движок использует через [fal.ai](https://fal.ai/pricing) по умолчанию, для чего каждая подходит, какие у неё ограничения и сколько она стоит. **Это не ограничение:** можно взять любую модель fal, см. [как сменить модель](#как-сменить-модель). Обзор всех инструментов, не только моделей: [стек](stack.md).

Цены сверены по страницам моделей 2026-11-05. Они меняются, поэтому перед оплатой сверяй их снова. API цен fal может отдавать только минимальную цену: например, у Kling 4.0 это цена за 720p.

**Статусы:**

- ✅ **Основная:** используем по умолчанию.
- 🧪 **Проверена:** наш тест прошла, но не основная.
- ⚠️ **Не проверена:** данные только из документации.

Оценки качества сделаны по одному запуску и по кадрам, это первое впечатление. Нигде в документации моделей пение не заявлено отдельно.

## Рецепт реализма

Подтверждён пользователем 2026-11-05 на одном клипе 7 с: кадр `02-studio-3`, пение в H3 Max в 1080P, губы попадают. Основным с 2026-11-06 стало разрешение 768P, в нём губы на слух ещё не проверялись. Широкие планы и связка Kling с Sync-3 на полном миксе пользователя не устроили.

**Кадр:**

- Средний или крупный план. Широкие планы пока выглядят как ИИ.
- Сумерки или полумрак, приглушённые цвета, лицо частично в тени, сильное размытие фона.
- Дефекты настоящей съёмки: кадр не по центру, фокус чуть мимо лица, смазывание, шум в тенях, лёгкий блик.
- Редкие бледные веснушки, неровная кожа, серьёзное лицо, взгляд мимо камеры.
- Сложные предметы вроде микрофона не прорисовывать: оставлять размытым краем на переднем плане.

**Пение:**

1. Отделить вокал в Demucs.
2. Подать в H3 Max чистый вокал, `resolution: 768P`, `enable_transcription: false`.
3. В ролике оставить полный микс: заменить звук клипа дорожкой трека с той же позиции.

**Обработка в ролике:** `story-clip` с `look: film`, покачивание `sway` только на неподвижном поющем плане. Выбран пользователем 2026-11-06: картинка чётче и насыщеннее, чем у `film-strong`. В `film` есть лёгкое зерно, полностью его убирает отсутствие поля `look`.

**Что считать:** поющий план в 768P вдвое дешевле плана Kling 4.0 в 720p: $0,08/с против $0,157/с.

## Как сменить модель

Подходит любая модель fal. Модель задаётся параметром команды, Remotion получает обычный MP4:

```bash
cd engine
npm run generate -- --endpoint <адрес модели> --input <input.json> --out <путь без расширения> --upload image_url=<кадр> --upload audio_url=<звук>
```

1. Посмотреть в этом гайде адрес и ограничения. Для новой модели сверить её схему на странице `fal.ai/models/<адрес>/api`, включая формат ответа.
2. Посчитать цену с учётом разрешения и длительности и подтвердить её.
3. Если модель не принимает файлы напрямую и возвращает ошибку `422`, передавать их через `--upload`.
4. Записать результат в карточку запуска и, если меняется основная модель, в этот гайд и `ai/context/decisions.md`.

Если запрос оборвался, оплаченный результат забирается без новой оплаты: `npm run generate -- --resume --out <тот же путь>`. Пока рядом лежит `<путь>.request.json`, новый запрос с этим `--out` не отправится. Чтобы отказаться от результата, удали этот файл.

Готовый результат скрипт тоже не перезаписывает: если есть `<путь>.json`, запрос не отправится. Дубль сохраняй с суффиксом `-2`, старый не удаляй.

**Нестандартный ответ модели:** скрипт сохраняет файлы из массива `images` и из полей с `url` на верхнем уровне ответа. На другом формате, например массиве `videos`, он остановится с ошибкой `No media in result`, и `--resume` её не исправит. Это задача агента, а не пользователя: забрать файл по ссылке из ошибки или из ответа по `responseUrl` с ключом из `.env`, сохранить его рядом с записью о запросе и удалить `<путь>.request.json`. Новый запрос для этого не нужен.

Персонаж при смене модели не меняется: референсы — обычные картинки. Разные модели отдают разные размеры кадра, поэтому в ролике клип нужно подгонять под 1080×1920.
