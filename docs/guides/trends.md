# Гайд: анализ трендов

Раз в неделю. Цена: $0.

> **Статус:** скилл `trend-analyze` работает, замеры проверены на роликах из `ref/`. На настоящей недельной выборке отчёт ещё не собирался.

## Шаги

1. **Открыть Reels Trends** в профессиональной панели Instagram в приложении.
2. **Сохранить 10–20 роликов файлами** в `trends/<YYYY-MM-DD>/music/`.
3. **Записать в `notes.md`** ссылки, просмотры и трендовые звуки, которых нет в файлах.
4. **Запустить `/trend-analyze`.**
   - `npm run analyze-video` снимает размер, склейки, громкость и кадры.
   - Агент разбирает крючок, темп, подписи и структуру.
   - Результат: `report.md` по [шаблону](../../templates/trend-report.md).
5. **Выбрать идеи** и указать отчёт в брифе следующего рилса.

## Что важно

- Трендовые звуки, вероятно, нужно добавлять в приложении при публикации.
- Результаты своих рилсов из карточек в `published/` сравниваются с трендами в каждом отчёте.
- Автосбор выключен, см. [правила](../../ai/context/rules.md).
