# Гайд: агенты

Движок не привязан к одному инструменту. Правила лежат в `AGENTS.md`, скиллы в `ai/skills/`, а каждый агент находит их по своим путям.

> **Статус:** рабочий сценарий пройден только в Claude Code. OpenCode и Codex настроены, сценарий в них ещё не проходил, см. [статус проверки](#статус-проверки).

| | Claude Code | OpenCode | Codex |
|---|---|---|---|
| **Правила** | `CLAUDE.md`, он подключает `AGENTS.md` | `AGENTS.md` | `AGENTS.md` |
| **Скиллы** | `.claude/skills/` | `.agents/skills/` и `.claude/skills/` | `.agents/skills/` |
| **Настройки проекта** | `.claude/` | `opencode.json` | `.codex/config.toml` |
| **Запустить скилл** | `/имя` | `@имя` в сообщении | `$имя` или `/skills` |
| **Без автозапуска** | `disable-model-invocation: true` | То же поле в v2, правило `ask` в `opencode.json` | `allow_implicit_invocation: false` в `agents/openai.yaml` |
| **Проверено** | ✅ Рабочие сценарии | ⚠️ Конфиг принят, сценарий не пройден | ⚠️ Запуска не было, настройка по документации |

В гайдах скиллы записаны как `/имя`. В другом агенте запускай их его способом.

---

## Какие скиллы не запускаются сами

`character-create`, `shot-frames`, `clip-generate`, `publish-package`: первые три платные, четвёртый ведёт к публикации.

Новый скилл в OpenCode по умолчанию спрашивает подтверждение. Безопасный добавляй в список `allow` в `opencode.json`.

---

## Платные запросы

Правило для всех агентов одно: сначала показать стоимость и дождаться ответа пользователя, см. [правила](../../ai/context/rules.md).

В OpenCode к нему добавлена техническая защита: `npm run generate` спрашивает подтверждение. В Claude Code и Codex разрешения зависят от настроек пользователя. Если разрешаешь все команды подряд, защитой остаётся только правило для агента.

## Настройка

### Claude Code

Ничего настраивать не нужно. Studio и галерею можно смотреть во встроенном браузере [Claude Desktop](https://code.claude.com/docs/en/desktop) или обычном браузере.

### OpenCode

```bash
opencode
```

- Ключ провайдера и модель настраиваются в самом OpenCode: `opencode auth`, `opencode models`.
- Модель выбирай с поддержкой инструментов и хорошим русским: скиллы длинные, а план съёмки и промпты зависят от её качества.
- Настройка проверена на v2.0.25 по [документации v2](https://opencode.ai/v2/docs/skills/). Скиллы искались в `.agents/skills` и `.claude/skills`: оба пути ведут к одним файлам.

### Codex

```bash
codex
```

- При первом запуске отметь проект как доверенный: иначе Codex не прочитает `.codex/config.toml`.
- Этот файл включает сеть в режиме `workspace-write`: она нужна для шрифтов при рендере и для fal.ai.
- ⚠️ В [отчёте пользователя](https://github.com/openai/codex/issues/10390) на macOS настройка не действовала. Если рендер или генерация падают с ошибкой сети, проверь это первым.

## Что отличается вне Claude Desktop

- **Remotion Studio:** запусти командой из `/remotion-compose` и открой ссылку в браузере.
- **Галерея:** собери `npm run review` и открой `review.html` в браузере: `open work/<run-id>/review.html`.
- **Клипы и аудио:** агент может не видеть или не слышать их. Оценку на слух всегда делает человек.

## Статус проверки

Заполняется по факту. Сценарий проверки: создание запуска скиллом и тестовый рендер, без денег.

| Агент | Что проверено | Результат |
|---|---|---|
| Claude Code | Весь сценарий на реальных роликах | ✅ |
| OpenCode | v2.0.25 принял `opencode.json`, правило на `npm run generate` применилось. Локальный `GET /api/skill` вернул пустой список и для глобальных скиллов, поэтому поиск скиллов так не подтвердить | ⚠️ Сценарий с моделью не запускали |
| Codex | Только структура файлов по [документации](https://learn.chatgpt.com/docs/build-skills) | ⚠️ Запуска не было |

Как пройти проверку: открой проект в агенте и напиши запрос ниже. Деньги не тратятся. Результат запиши в эту таблицу.

```text
Создай скиллом reel-new запуск <дата>-music-agent-test: формат story-clip, персонажа и трек пока не указывай, это проверка.
Из папки engine выполни npm ci и npm run render:smoke.
Скажи, какой файл получился и какие у него размер и частота кадров.
```
