# Гайд: установка

Этот репозиторий содержит движок без контента. Он скачивается один раз, дальше это обычная папка без git: все операции выполняет агент. Обновлений нет.

---

## Установить

Вести установку будет агент: он сам задаёт вопросы и говорит, что делать дальше. Git не нужен, Терминал может понадобиться один раз, агент предупредит об этом.

Нужен Mac с macOS 13.5 или новее и свой [агент](agents.md) с подпиской или ключом. Remotion официально требует macOS 15: на более старой системе агент проверит рендер тестом, а если он не пойдёт, готовый материал соберёт человек с рабочим движком. Бесплатный план Claude не включает Claude Code.

1. **Скачать движок.** Написать агенту:

   ```text
   Скачай движок в папку Siren на рабочем столе. Git не используй. Если папка уже есть, ничего не перезаписывай и спроси меня. Команда:
   test ! -e ~/Desktop/Siren && mkdir ~/Desktop/Siren && curl -fsSL https://github.com/it-publisher/Siren/archive/refs/heads/main.tar.gz | tar -xz --strip-components=1 -C ~/Desktop/Siren
   ```

2. **Открыть папку `Siren` как проект** в новом чате агента: только так он увидит скиллы.
3. **Написать в новом чате «Начнём».** Агент запустит `/music-start` и проведёт по шагам: инструменты, ключ fal.ai, тестовый рендер, персонаж, первый рилс.

Ключ `FAL_KEY` вставляется только в файл `.env`, который агент откроет в TextEdit. В чат его присылать нельзя.

Готово, когда создан свой персонаж и рилс.

Расходы твои: свой аккаунт fal.ai и свой ключ.

## Резервная копия

У копии нет истории изменений, поэтому резервная копия — единственный способ вернуть файлы.

- **Что копировать:** всю папку проекта. Самое ценное — `characters/*/references/`.
- **Как:** Time Machine или копия папки на внешний диск.
- **Когда:** регулярно и перед опасными изменениями.
- **Осторожно:** в копии лежит `.env` с ключами, поэтому не загружай её в общие или публичные облака.
