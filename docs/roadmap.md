# Дорожная карта

## Этапы

- [x] **Основа движка:** проект Remotion, тестовый MP4 1080×1920.
- [x] **Тайминги:** тайминги Whisper переносятся на текст песни.
- [x] **Тест генерации:** кадры Seedream 4.5, пение MiniMax H3 Max Lip Sync, клип без пения на Kling 4.0. Выводы: [гайд по моделям](guides/models.md).
- [ ] **Формат `talking-closeup`:** шаблон и сборка работают на 10 с. Осталось проверить длинный клип и синхрон на слух.
- [ ] **Формат `story-clip`:** шаблон и сборка работают на 21 с, губы подтверждены на слух на клипе 7 с в 1080P. Осталось оценить ролик целиком и губы в 768P.
- [x] **Рабочие скиллы:** команды проверены, бесплатные на реальных файлах, платные на ручных запусках.
- [ ] **Платный прогон скиллами:** один `story-clip` от персонажа до MP4.
- [ ] **Установка копии:** ведущий один раз скачивает движок через агента и дальше работает у себя. Готово, когда он сам создал своего персонажа и рилс.
- [ ] **Форматы `lyric-performance` и `cinematic-story`.**
- [ ] **Поддержка OpenCode и Codex:** файлы настройки готовы, см. [гайд](guides/agents.md). Готово, когда сценарий проверки прошёл в каждом инструменте.
- [ ] **Анализ трендов на настоящей выборке:** скилл `trend-analyze` работает, нужен первый недельный отчёт.
- [ ] **Автопроверка:** контрольные кадры, наложения, обрезанный текст.
- [ ] **Полная автоматизация:** запуск без ручных проверок. Понадобится `claude -p` или Claude API, условия проверить отдельно.
- [ ] **Автопубликация (опционально):** Instagram API.
