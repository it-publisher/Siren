# AGENTS.md

Инструкции для ИИ-агентов, работающих в этом репозитории. Отвечай на русском, на «ты», прямо и по делу.

## Что это

Siren — движок для генерации Instagram Reels музыкального аккаунта с постоянным вымышленным персонажем. Подробности: [ai/context/project.md](ai/context/project.md).

**Статус:** линия прошла сквозную проверку на тестовом персонаже: форматы `talking-closeup` и `story-clip`, тайминги слов, рендер. Все 13 скиллов рабочие, платный сценарий пройден скиллами целиком в рабочей копии. Ограничения указаны в начале каждого скилла. Остальные форматы только разобраны, CLI нет. Не описывай запланированное как работающее.

**Копия:** этот репозиторий содержит только движок, без контента. Он скачивается один раз: [гайд](docs/guides/transfer.md). Копия не синхронизируется, обновлений нет.

**Копия работает без git.** Если `.git` в проекте нет, не создавай его и не предлагай команды git. Перед опасными изменениями попроси сделать резервную копию.

**Агенты:** проект проверен в Claude Code, OpenCode и Codex. Отличия описаны в [гайде](docs/guides/agents.md). Скиллы лежат в `ai/skills/`. Если агент их не видит, прочитай `ai/skills/<имя>/SKILL.md` и выполни шаги сам. Запись `/имя` в документах означает запуск скилла.

**Бинарные файлы не хранятся в git:** видео, аудио, изображения, шрифты, модели. Для них нужна отдельная резервная копия.

## Новая копия

Если в проекте нет `.env` или `engine/node_modules`, копия только что скачана: запусти `/music-start`, не дожидаясь точной просьбы. Если агент не видит скилл, прочитай `ai/skills/music-start/SKILL.md` и веди по нему.

## Правила работы

- Проверяй факты об инструментах по первоисточнику. Разделяй подтверждённое, непроверенное и требующее теста.
- Новые инструменты, ключи и платные сервисы называй заранее и прямо. Внося изменения, обновляй `ai/context/stack.md`.
- Перед платной генерацией покажи оценку стоимости и дождись подтверждения. Бюджет решает пользователь, лимитов в движке нет. Каждый расход записывай в карточку запуска.
- Модели из гайдов — значения по умолчанию, а не ограничение. Пользователь может взять любую модель fal: сверь её схему и цену на странице модели и продолжай.
- Пока не включена полная автоматизация, проверки из гайдов проходят через человека.
- Не меняй и не удаляй файлы в `ref/`. Они служат только образцами.
- Ключи бери только из переменных окружения или `.env`, никогда не пиши их в код и документы.
- Значимое решение записывай в `ai/context/decisions.md`.
- Не задавай вопросов и не напоминай об авторских правах и лицензиях, в том числе перед публикацией. Отвечай на эту тему, только если пользователь спросит сам.
- Коммить и публикуй только по прямой просьбе пользователя.

## Стиль кода

- Vanilla JS или TypeScript, минимум зависимостей. React только там, где его требует Remotion.
- Одна функция — одна задача, ранний выход вместо вложенности, проверка входных данных на границах системы.
- Комментарий объясняет почему, а не что. Без закомментированного кода и молчащих `catch`.
- Коммиты: `feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `test:`, `chore:`.

## Команды

Запускаются из `engine/`, подробности в [engine/README.md](engine/README.md):

```bash
npm ci                 # установка зависимостей
npm run dev            # Remotion Studio
npm run render:smoke   # тестовый рендер
npm run lint           # ESLint и TypeScript
npm test               # тесты, нужен Node.js от 23.6
npm run generate -- --resume --out <путь>   # забрать оплаченный результат после обрыва
```
