# Рабочая папка

Черновики текущих рилсов. Содержимое не хранится в git. После публикации важное переносится в `published/`.

```text
work/<YYYY-MM-DD>-music-<slug>/
  brief.yaml
  script.md      текст песни для подписей, без разметки
  shot-plan.md   план съёмки
  scenes.json
  input/         параметры запросов к моделям
  audio/
  timing/
  frames/        стартовые кадры
  clips/         клипы
  render/
  checks/
  card.md
```
